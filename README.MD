# 📌 Mi Portafolio Personal - Desarrollador Web

## 🧾 Descripción del Proyecto

Este proyecto consiste en el desarrollo de un portafolio web personal como parte de la Práctica Formativa Obligatoria 1. El objetivo es aplicar conocimientos de HTML5 y CSS3 para construir una página web estructurada, estilizada y responsiva, que incluya información personal, proyectos, habilidades y un formulario de contacto. Se implementaron buenas prácticas de desarrollo, diseño adaptable y mejoras de experiencia de usuario mediante animaciones y organización del contenido.
